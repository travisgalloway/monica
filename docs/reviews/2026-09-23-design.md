## 2. Findings

Ranked by severity, then by verdict, with CONFIRMED before PLAUSIBLE.

### High

**DSN-c38694b2** · `src/data/r2_sync.py:69` · rule `read-modify-write-race` · severity high ·
verdict CONFIRMED

`upload_dir` walks a local directory and uploads each file individually, writing no manifest and
no commit marker. Python's `sorted()` places the `LATEST` pointer file before the `slot-a`/`slot-b`
directories, by ASCII order. An interrupted sync can therefore publish `LATEST` before the
checkpoint slot files it names finish uploading. `docs/design/08-corpus-pipeline.md` directs
operators to this same path for durability during a multi-day training run.

Disposition: ticketed as #440.

### Medium

**DSN-1eb7dfcb** · `src/train/verifiers.py:27` · rule `import-cycle` · severity medium · verdict
CONFIRMED

`verifiers.py` sets `__path__` at runtime to turn itself into a pseudo-package. Its eight
submodules import back from it. The one strongly connected component found in the import graph
works only because of import ordering. A future reorder could break it with a partial-init
`ImportError`.

Disposition: ticketed as #444.

**DSN-538dc8a8** · `tests/test_import_guard.py:32` · rule `layering-violation` · severity medium ·
verdict CONFIRMED

Six modules import no hardware library but are absent from `PORTABLE_MODULES`. They are
`src/runtime/sandbox.py` and five `src/train/verifiers/*.py` submodules: `architecture.py`,
`execution.py`, `mutations.py`, `refactoring.py`, `schema_evolution.py`. Five sibling verifier
submodules are already listed. The gap is inconsistent within one package, not a deliberate
exclusion.

Disposition: ticketed as #445.

**DSN-2a62656c** · `src/train/verifiers/` (multiple files) · rule `swallowed-error` · severity
medium · verdict CONFIRMED

Of 85 enumerated `except Exception`/`except BaseException` sites, 35 have a body that is exactly
`pass`. Six match already-parked entries. Twenty-nine are new, concentrated in
`src/train/verifiers/{mutations,execution,refactoring}.py` and `verifiers.py` itself. These sites
sit in RLVR reward-computation paths. A silent swallow there could mis-score a reward with no log
line distinguishing "not applicable" from "crashed."

Disposition: recorded under Decisions needed, below.

**DSN-f2d65e43** · `src/data/shard.py:116` · rule `read-modify-write-race` · severity low ·
verdict CONFIRMED

`pack_atomic` writes each shard file and the manifest directly to its final name, with no
temp-file-and-rename step. `open_shard` falls back silently to the default dtype when the manifest
is missing, rather than raising. The risk here is lower than `upload_dir`'s. `pack_atomic` is an
operator-run offline batch step, not an unattended multi-day sync, and most interruptions fail
loud.

Disposition: parked.

**DSN-e91b320f** · `docs/design/07-configs-and-decisions.md:163-168` · rule `doc-unimplemented` ·
severity low · verdict CONFIRMED

The document calls tied embeddings "not a tuning knob but a requirement." `MambaConfig.validate()`
carries no check enforcing `tie_embeddings`. A config author can set it to `false` on a large-vocab
config, and the model still validates and runs.

Disposition: parked.
